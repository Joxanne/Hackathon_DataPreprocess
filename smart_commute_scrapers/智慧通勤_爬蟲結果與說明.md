## ❌ 無法爬取的資料集（3 個）

### 新北市路邊停車即時空位
- **原因**: `data.ntpc.gov.tw` 的 WAF（Web Application Firewall）對所有非瀏覽器的程式化請求一律回傳 `Request Rejected`，即使加入 Referer 與標準 User-Agent 也無法繞過。
- **替代方案**: 需登入 [https://data.ntpc.gov.tw/](https://data.ntpc.gov.tw/) 填寫申請介接表單，取得授權後方可呼叫。

### Gogoro 換電站即時電池庫存
- **原因**: Gogoro 無公開 JSON API。過去社群使用的非官方端點（逆向工程自官方 App）已被停用或需要 App Token。TDX 上的 Gogoro 資料**僅提供靜態站點位置**，不含即時庫存。
- **替代方案**: 使用 TDX 靜態站點（需 Token），或聯繫 Gogoro 申請企業合作 API。

### Waze for Cities 即時路況
- **原因**: 屬於政府合作方案（Waze Connected Citizens Program），僅開放給地方政府機關，非學術或民間開發者可申請。
- **替代方案**: 無直接替代，可考慮改用台北市 VD 速率資料（`04_road_speed_taipei.py`）作為道路壅塞程度的替代指標。
